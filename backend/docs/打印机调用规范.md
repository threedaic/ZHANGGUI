# 打印机调用规范

> **开发者备忘录**：任何涉及打印功能的模块，必须遵循此规范。

---

## 核心原则

**一次配置，全局调用**。打印机配置集中在「设置端 → 打印机管理」，所有模块通过统一API调用。

---

## 调用方式

### 方式一：根据分类自动路由（推荐）

适用于：订单、存酒、取酒等有商品分类的场景。

```typescript
// 前端调用
import { printersAPI } from '@/api/printers'

await printersAPI.printByCategory({
  category_id: 'xxx',           // 商品分类ID
  content: '打印内容',           // 文本内容
  document_type: 'order',       // order=出单 / receipt=收据 / label=标签
  trigger: 'order_created'      // order_created / payment_completed / manual
})
```

```python
# 后端调用
from app.services.printer_service import PrinterService

async def your_function(db: AsyncSession, store_id: UUID, category_id: UUID):
    service = PrinterService(db)
    result = await service.print_by_category(
        store_id=store_id,
        category_id=category_id,
        content="打印内容",
        document_type="order",      # order / receipt / label
        trigger="order_created",    # order_created / payment_completed / manual
    )
    # result: {"status": "sent"/"queued"/"no_printer", "printer": "打印机名"}
```

### 方式二：直接打印到指定打印机

适用于：明确知道要用哪台打印机的场景。

```typescript
await printersAPI.printDirect({
  printer_id: 'xxx',
  content: '打印内容'
})
```

### 方式三：通过路由规则ID打印

适用于：使用高级路由规则的场景。

```python
result = await service.print_by_route(store_id, route_id, content)
```

---

## 打印机类型

| 类型 | 代码 | 用途 | 典型场景 |
|------|------|------|----------|
| 出单机 | `order` | 厨房/吧台出单 | 订单创建时，餐食→厨房，酒水→吧台 |
| 小票机 | `receipt` | 客户收据 | 支付完成时打印小票 |
| 标签机 | `label` | 标签打印 | 存酒标签、商品标签 |

---

## 路由优先级

系统按以下优先级查找打印机：

```
1. 自定义路由规则（高级模式）
   ↓ 未匹配
2. 分类绑定打印机（简单模式）
   ↓ 未绑定
3. 按打印机类型自动路由
   ↓ 未找到
4. 提示"没有可用打印机"
```

---

## 故障处理

- 打印机离线 → 自动使用备用打印机
- 打印失败 → 自动加入队列，每30秒重试
- 重试3次仍失败 → 记录日志，可手动重打

---

## 模块开发清单

开发新模块时，如果涉及打印，请检查：

- [ ] 确定打印时机（订单创建/支付完成/手动）
- [ ] 确定文档类型（出单/收据/标签）
- [ ] 确定商品分类（用于路由）
- [ ] 调用统一打印接口
- [ ] 处理打印结果（成功/失败/无打印机）

## 各模块调用示例

### 收银台（待开发）

```typescript
// 收银台 - 支付完成后打印小票
async function onPaymentComplete(order: Order) {
  // 打印客户小票
  await printersAPI.printByCategory({
    category_id: order.items[0].category_id,  // 任取一个分类
    content: generateReceipt(order),           // 生成小票内容
    document_type: 'receipt',
    trigger: 'payment_completed'
  })
}
```

### 存酒模块

```typescript

    await printersAPI.printByCategory({
      category_id: item.category_id,
      content: generateOrderItem(item),
      document_type: 'order',
      trigger: 'order_created'
    })
  }
}
```

## 配置入口

**设置端 → 打印机管理**

- 打印机列表：添加/编辑/删除打印机
- 路由规则：高级自定义路由
- 分类绑定：简单模式，为每个分类指定打印机

---

## 注意事项

1. **不要硬编码打印机**：使用分类路由，不要写死打印机ID
2. **不要单独配置**：所有打印机配置集中在管理端
3. **统一调用方式**：使用 `printersAPI.printByCategory` 或 `printDirect`
4. **处理异常情况**：打印失败时给出用户提示

## API 参考

| 接口 | 方法 | 说明 |
|------|------|------|
| `/printers/print` | POST | 根据分类自动路由 |
| `/printers/print/direct` | POST | 直接打印到指定打印机 |
| `/printers` | GET | 获取打印机列表 |
| `/printers` | POST | 添加打印机 |
| `/printers/{id}/test` | POST | 测试打印 |
| `/printers/routes` | GET/POST | 路由规则管理 |
| `/printers/categories` | GET | 分类打印机绑定 |
