# 易联云打印机对接教程

## 一、易联云打印机简介

易联云是国内领先的云打印机服务商，提供稳定的云打印服务。使用易联云打印机的优势：

- **无需本地网络**：打印机通过4G/WiFi连接云端，只要有电就能打印
- **全国覆盖**：支持全国范围内的打印机部署
- **稳定可靠**：7x24小时在线，打印成功率99.9%
- **多场景支持**：支持出单、小票、标签等多种打印需求

## 二、购买易联云打印机

### 2.1 购买渠道

1. **官方商城**：[易联云官方商城](https://www.10ss.net/)
2. **淘宝/京东**：搜索"易联云打印机"
3. **线下代理商**：联系当地代理商

### 2.2 推荐型号

| 型号 | 用途 | 纸宽 | 特点 |
|------|------|------|------|
| ET521 | 出单/小票 | 80mm | 热敏打印，速度快，适合厨房/吧台 |
| ET321 | 标签 | 58mm | 标签打印机，适合存酒标签 |
| ET581 | 小票 | 58mm | 经济实惠，适合收银台 |

## 三、注册易联云开放平台

### 3.1 访问开放平台

1. 打开浏览器，访问：https://www.10ss.net/open/
2. 点击"注册"按钮

### 3.2 注册账号

1. 填写手机号码
2. 获取验证码
3. 设置密码
4. 完成注册

### 3.3 实名认证

1. 登录后，进入"账号管理"
2. 选择"实名认证"
3. 上传身份证照片
4. 等待审核（通常1-2个工作日）

## 四、添加打印机设备

### 4.1 获取打印机SN码

1. 打开打印机包装
2. 找到打印机背面的贴纸
3. 记录SN码（12位数字字母组合）

### 4.2 在平台添加设备

1. 登录易联云开放平台
2. 进入"设备管理" → "添加设备"
3. 输入打印机SN码
4. 设置打印机名称（如"厨房出单机"）
5. 点击"确认添加"

### 4.3 验证打印机状态

1. 在设备列表中查看打印机
2. 确保状态显示为"在线"
3. 如果显示"离线"，检查打印机电源和网络连接

## 五、获取API密钥

### 5.1 创建应用

1. 登录易联云开放平台
2. 进入"应用管理" → "创建应用"
3. 填写应用名称（如"CRUSH管理系统"）
4. 选择应用类型："Web应用"
5. 点击"创建"

### 5.2 获取密钥

创建成功后，系统会生成两个重要信息：

- **应用ID (client_id)**：类似 `1234567890`
- **应用密钥 (client_secret)**：类似 `abcdef1234567890abcdef1234567890`

**重要提示**：请妥善保管应用密钥，不要泄露给他人！

### 5.3 配置回调地址（可选）

如果需要接收打印状态通知：

1. 在应用设置中找到"回调配置"
2. 填写回调URL：`https://your-domain.com/api/v1/printers/callback`
3. 保存配置

## 六、在系统中配置打印机

### 6.1 进入打印机管理

1. 登录CRUSH管理系统
2. 进入"设置" → "打印机管理"
3. 点击"+ 添加打印机"

### 6.2 填写配置信息

按照以下信息填写：

| 字段 | 说明 | 示例 |
|------|------|------|
| 打印机名称 | 自定义名称 | 厨房出单机 |
| 打印机类型 | 选择用途 | 出单机 |
| 打印机品牌 | 选择品牌 | 易联云 |
| 设备SN | 打印机背面SN码 | 123456789012 |
| 应用ID | 开放平台获取 | 1234567890 |
| 应用密钥 | 开放平台获取 | abcdef1234567890 |
| 纸宽 | 根据打印机型号 | 80mm |

### 6.3 测试打印

1. 保存配置
2. 在打印机列表中找到刚添加的打印机
3. 点击"测试"按钮
4. 等待打印机输出测试页

## 七、配置打印场景

### 7.1 进入模块配置

1. 在打印机管理页面，切换到"模块配置"标签
2. 查看系统支持的打印场景

### 7.2 启用需要的场景

根据业务需求，启用相应的打印场景：

| 场景 | 说明 | 推荐打印机类型 |
|------|------|----------------|
| 收银台-小票打印 | 顾客消费小票 | 小票机 |
| 厨房-出单打印 | 厨房订单 | 出单机 |
| 吧台-出单打印 | 酒水订单 | 出单机 |
| 存酒-标签打印 | 存酒标签 | 标签机 |
| 预订-确认单 | 预订确认 | 小票机 |

### 7.3 绑定打印机

1. 启用场景后，选择对应的打印机
2. 可以选择"自动选择（按类型）"让系统自动分配
3. 也可以手动指定具体打印机

## 八、高级配置

### 8.1 路由规则

如果需要将不同类型的订单发送到不同打印机：

1. 切换到"路由规则"标签
2. 点击"+ 添加规则"
3. 设置规则名称、触发条件、目标打印机

例如：
- 规则名称："酒水→吧台"
- 匹配条件："按商品分类"
- 选择酒水分类
- 目标打印机："吧台出单机"

### 8.2 故障转移

系统支持主备打印机切换：

1. 在"分类绑定"中设置主打印机
2. 设置备用打印机
3. 当主打印机离线时，自动切换到备用打印机

## 九、常见问题

### 9.1 打印机显示离线

**可能原因：**
- 打印机电源未开启
- 网络信号弱
- 打印机未正确添加到平台

**解决方法：**
1. 检查打印机电源指示灯
2. 将打印机移到信号更好的位置
3. 在易联云平台重新添加设备

### 9.2 测试打印失败

**可能原因：**
- 应用ID或密钥错误
- 设备SN码错误
- 打印机缺纸

**解决方法：**
1. 核对应用ID和密钥
2. 确认设备SN码正确
3. 检查打印机纸卷

### 9.3 打印内容乱码

**可能原因：**
- 打印机型号与配置不匹配
- 纸宽设置错误

**解决方法：**
1. 确认打印机型号
2. 调整纸宽设置（58mm或80mm）
